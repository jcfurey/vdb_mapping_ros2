VDB Mapping ROS2 Package
===
DISCLAIMER: This library is still under development. Be warned that some interfaces will be changed and/or extended in the future.

Currently supported features:
- Fast ray tracing during map creation
- Remote mapping support (exchange maps between different mapping instances)
- Multi-threading for each sensor source
- 2D occupancy grid generation with free/unknown space distinction

The VDB Mapping ROS2 Package is a ROS2 wrapper around [VDB Mapping](https://github.com/fzi-forschungszentrum-informatik/vdb_mapping)

## Getting Started

### Requirements
This library requires [OpenVDB](https://www.openvdb.org/) as it is built around it. This library was initially developed using Version 5.0 and should work with all versions above.
Either use the apt package which will be automatically installed via rosdep or compile the package from source using the provided [build instructions](https://github.com/AcademySoftwareFoundation/openvdb)

The wrapper requires a version of the `vdb_mapping` core library that provides the transformable-section API (`transformAndApplyMapSection*`). At the time of writing this is the `devel` branch.

### Build instructions

Since the required VDB Mapping library is a plain C++ package, you have to use [colcon build](https://colcon.readthedocs.io/en/released/) to build the workspace.

``` bash
# source global ros
source /opt/ros/<your_ros_version>/setup.bash

# create a colcon workspace
mkdir -p ~/colcon_ws/src && cd ~/colcon_ws/src

# clone packages (note the devel branch of the core library)
git clone -b devel https://github.com/fzi-forschungszentrum-informatik/vdb_mapping
git clone https://github.com/fzi-forschungszentrum-informatik/vdb_mapping_ros2

# install dependencies
sudo apt update
rosdep update
rosdep install --from-paths src --ignore-src -y

# build the workspace
cd ~/colcon_ws && colcon build

# source the workspace
source install/setup.bash
```

### Running

``` bash
ros2 launch vdb_mapping_ros2 vdb_mapping_ros2.py        # Main mapping (multi-threaded container)
ros2 launch vdb_mapping_ros2 vdb_map_server_ros2.py     # Map server
ros2 launch vdb_mapping_ros2 vdb_remote_mapping_ros2.py # Remote mapping instance
```

The node is provided as a composable component (`vdb_mapping_ros2::VDBMappingROS2`) and additionally as a standalone executable (`vdb_mapping_ros_node`).

## Remote Mapping
The remote mapping module is mainly designed to provide external access to the map, without saving and loading it in a different node. In our case we use it to visualize the map data on a remote base station which is then used to control the robots from far away and give the user an overview of the area the robot operates in. Basically it is a full additional mapping node which can access the data chunks generated by the main mapping on the robot. These can then be integrated into the remote mapping instance to generate the same or a similar map depending on the chosen parameter settings.

The exchanged data are OpenVDB grids which are compressed and serialized as a bitstream before sending them out over the network. Two mechanics are available:

#### Sections
Sections are not bound to the sensor data rate but are generated with a defined rate around a configurable frame. The binary occupancy state of a section around that frame is copied out of the map and transformed into an update grid that can be applied to a remote instance. Although this creates additional overhead it is highly useful in scenarios with transmission delay and package loss, since each section contains a complete chunk of the map while still being small with respect to the bandwidth.

#### Full sections
Full sections work like sections, but instead of an update grid the full occupancy grid data of the section (including the probabilistic state) is serialized and exchanged. They are heavier on the network but preserve the probabilistic framework on the remote side.

In addition to the periodic topics, a remote instance can actively pull a section from another instance using the `trigger_map_section_update` / `trigger_map_full_section_update` services, and remote sources can be enabled or disabled at runtime via `toggle_remote_source`.

## ROS API
### ROS Parameters
VDB Mapping is highly configurable using ROS parameters. Below is a complete list of all available parameters. Internally we store them in a yaml configuration file, see the [config directory](vdb_mapping_ros2/config) for examples.

#### Basic Parameters

| Parameter Name                      | Type    | Default | Information |
| ----------------------------------- | ------- | ------- | ----------- |
| map_frame                           | string  | ''      | Coordinate frame of the map |
| robot_frame                         | string  | ''      | Coordinate frame of the robot |
| resolution                          | double  | 0.05    | Map resolution in meters |
| max_range                           | double  | 10.0    | Global maximum raycasting range (can also be set for each sensor source individually) |
| prob_hit                            | double  | 0.7     | Probability update if a beam hits a voxel |
| prob_miss                           | double  | 0.4     | Probability update if a beam misses a voxel |
| prob_thres_min                      | double  | 0.12    | Lower occupancy threshold of a voxel |
| prob_thres_max                      | double  | 0.97    | Upper occupancy threshold of a voxel |
| fast_mode                           | bool    | false   | Enables faster raycasting at the cost of modeling free and unknown space individually |
| map_directory_path                  | string  | ''      | Storage location for saved maps |
| tf_lookup_timeout                   | double  | 0.1     | How long TF lookups wait for available transforms (seconds) |
| two_dim_projection_threshold        | int     | 5       | Number of occupied voxels in a column above which the projected 2D occupancy grid cell becomes lethal |
| smooth_remote_sections              | bool    | false   | Smooth incoming remote sections before applying them |
| remote_section_smoothing_iterations | int     | 2       | Number of smoothing iterations for remote sections |
| artificial_negative_height          | double  | -0.5    | Downward extent of artificial areas (meters) |
| artificial_positive_height          | double  | 1.5     | Upward extent of artificial areas (meters) |
| apply_raw_sensor_data               | bool    | true    | Integrate raw sensor data (point clouds) into the map. Set to false for pure remote/map-server instances |
| accumulate_updates                  | bool    | false   | Accumulate the data of multiple sensor measurements before integrating it into the map (only used when apply_raw_sensor_data is true) |
| accumulation_period                 | double  | 1.0     | How long updates are accumulated before integration (seconds) |
| sources                             | string[]| []      | List of sensor sources |
| remote_sources                      | string[]| []      | List of remote sources |

#### Visualization Parameters

| Parameter Name         | Type   | Default | Information |
| ---------------------- | ------ | ------- | ----------- |
| visualization_rate     | double | 1.0     | Rate of the periodic map visualization (Hz). Values <= 0 disable the timer |
| publish_pointcloud     | bool   | true    | Publish the map as a point cloud |
| publish_vis_marker     | bool   | true    | Publish the map as a CUBE_LIST marker with height color coding |
| publish_occupancy_grid | bool   | true    | Publish a 2D occupancy grid projection of the map |
| z_limit_min            | double | 0.0     | Lower visualization z-limit relative to the robot frame (dynamically reconfigurable). Both limits equal disables clipping |
| z_limit_max            | double | 0.0     | Upper visualization z-limit relative to the robot frame (dynamically reconfigurable) |

#### Sensor Sources
Each entry of `sources` opens a namespace with the following parameters:

| Parameter Name      | Type   | Default | Information |
| ------------------- | ------ | ------- | ----------- |
| topic               | string | ''      | Topic name of the PointCloud2 sensor msg (required) |
| sensor_origin_frame | string | ''      | Frame used as raycast origin. Optional; by default the frame id of the msg is used. Useful for pre-aligned point clouds whose frame id is no longer the sensor origin |
| max_range           | double | 0       | Per-sensor max raycasting range. Optional; 0 uses the global max_range |
| max_rate            | double | 0       | Maximum integration rate for this source. Optional; 0 means unlimited |
| reliable            | bool   | false   | Use a reliable QoS subscription instead of best-effort |

#### Section Publishing (local side)

| Parameter Name                   | Type   | Default     | Information |
| -------------------------------- | ------ | ----------- | ----------- |
| publish_sections                 | bool   | false       | Periodically publish map sections as update grids |
| publish_full_sections            | bool   | false       | Periodically publish map sections as full grids |
| section_update.rate              | double | 1.0         | Rate at which sections are published (Hz, must be > 0) |
| section_update.frame             | string | robot_frame | Frame the section bounding box is centered around |
| section_update.min_coord.{x,y,z} | double | -10         | Min corner of the section bounding box relative to the section frame |
| section_update.max_coord.{x,y,z} | double | 10          | Max corner of the section bounding box relative to the section frame |

#### Remote Sources (remote side)
Each entry of `remote_sources` opens a namespace with the following parameters:

| Parameter Name             | Type   | Default | Information |
| -------------------------- | ------ | ------- | ----------- |
| namespace                  | string | ''      | Namespace of the remote mapping instance |
| apply_remote_sections      | bool   | false   | Subscribe to the remote instance's sections and apply them to the map |
| apply_remote_full_sections | bool   | false   | Subscribe to the remote instance's full sections and apply them to the map |
| autostart                  | bool   | true    | Whether the remote source starts active. Can be changed at runtime via the toggle_remote_source service |

#### Map Server

| Parameter Name              | Type   | Default | Information |
| --------------------------- | ------ | ------- | ----------- |
| map_server.initial_map_file | string | ''      | PCD file loaded into the map at startup (empty disables) |
| map_server.set_background   | bool   | false   | Set loaded points as background |
| map_server.clear_map        | bool   | false   | Clear the map before loading |

### Advertised ROS Topics

| Topic Name               | Type                                 | Information |
| ------------------------ | ------------------------------------ | ----------- |
| ~/vdb_map_visualization  | visualization_msgs/Marker            | Map visualization as voxel marker |
| ~/vdb_map_pointcloud     | sensor_msgs/PointCloud2              | Map visualization as point cloud |
| ~/vdb_map_occupancy      | nav_msgs/OccupancyGrid               | 2D projection of the map (lethal / free / unknown) |
| ~/vdb_map_sections       | vdb_mapping_interfaces/UpdateGrid    | Periodic map sections (if publish_sections) |
| ~/vdb_map_full_sections  | vdb_mapping_interfaces/UpdateGrid    | Periodic full map sections (if publish_full_sections) |

### Subscribed ROS Topics

| Topic Name                                | Type                              | Information |
| ----------------------------------------- | --------------------------------- | ----------- |
| {source.topic}                            | sensor_msgs/PointCloud2           | Point cloud input per sensor source |
| {remote_source.namespace}/vdb_map_sections      | vdb_mapping_interfaces/UpdateGrid | Sections of a remote instance (if apply_remote_sections) |
| {remote_source.namespace}/vdb_map_full_sections | vdb_mapping_interfaces/UpdateGrid | Full sections of a remote instance (if apply_remote_full_sections) |

### ROS Services

| Service Name                     | Type                                              | Information |
| -------------------------------- | ------------------------------------------------- | ----------- |
| ~/reset_map                      | std_srvs/Trigger                                  | Resets the current map |
| ~/save_map                       | std_srvs/Trigger                                  | Saves the current map to map_directory_path |
| ~/save_map_to_pcd                | std_srvs/Trigger                                  | Saves the current map as a PCD file |
| ~/load_map                       | vdb_mapping_interfaces/LoadMap                    | Loads the map specified in the request |
| ~/load_map_from_pcd              | vdb_mapping_interfaces/LoadMapFromPCD             | Loads a map from a PCD file |
| ~/get_map_section                | vdb_mapping_interfaces/GetMapSection              | Returns a serialized section of the map |
| ~/trigger_map_section_update     | vdb_mapping_interfaces/TriggerMapSectionUpdate    | Pulls a section from a remote instance and applies it |
| ~/trigger_map_full_section_update| vdb_mapping_interfaces/TriggerMapSectionUpdate    | Pulls a full section from a remote instance and applies it |
| ~/raytrace                       | vdb_mapping_interfaces/Raytrace                   | Raytraces a single ray and returns where it first intersects the map |
| ~/batch_raytrace                 | vdb_mapping_interfaces/BatchRaytrace              | Raytraces a batch of rays |
| ~/add_points_to_grid             | vdb_mapping_interfaces/AddPointsToGrid            | Sets the given points as occupied voxels |
| ~/remove_points_from_grid        | vdb_mapping_interfaces/RemovePointsFromGrid       | Removes the given points from the grid |
| ~/add_artificial_areas           | vdb_mapping_interfaces/AddArtificialAreas         | Marks polygonal areas as artificially occupied |
| ~/remove_artificial_areas        | std_srvs/Trigger                                  | Removes all artificial areas and restores map integrity |
| ~/toggle_remote_source           | vdb_mapping_interfaces/ToggleRemoteSource         | Activates or deactivates a remote source at runtime |
